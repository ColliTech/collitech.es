COLLITECH — WEB REWORK

Archivos:
- index.html       Inicio
- servicios.html   Servicios
- precios.html     Precios
- proyectos.html  Galería de proyectos
- resenas.html     Reseñas + formulario
- contacto.html    Contacto
- styles.css       Diseño compartido
- nav.js            Menú desplegable
- reviews.js        Supabase + reseñas
- collitech-logo.png

Para GitHub Pages:
1. Sustituye el index.html antiguo por estos archivos.
2. Sube TODOS los archivos al mismo nivel del repositorio.
3. Mantén collitech-logo.png junto a los HTML.
4. No cambies la URL ni la Publishable key de Supabase.
5. En proyectos.html puedes sustituir los bloques "Proyecto 01", etc. por tus fotos.

Las reseñas públicas se filtran por approved=true.
Las nuevas reseñas se insertan con approved=false por el valor por defecto de la tabla.
